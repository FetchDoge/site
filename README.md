# marcusrichards.dev

Source for [marcusrichards.dev](https://marcusrichards.dev) — the personal portfolio site of
Marcus Richards, AI Systems Operator & Automation Architect.

## What it is

A static HTML/CSS site (no build step, no framework). Every project page ships with its
evidence: claims carry their status, numbers carry receipts.

Pages:

| page | subject |
|---|---|
| `index.html` | home — positioning, doctrine, receipt-first intro |
| `aegis.html` | AEGIS — agent operating system for AI coding work |
| `ektar.html` | Ektar — private continuity agent |
| `labs.html` | lab notes / experiments |
| `catalyst-grant-2026.html` | Catalyst grant 2026 application material |

Shared stylesheet: `styles.css`. Static assets under `assets/`.

## Deploy

Plain static files — serve the repo root from any static host. Live at
https://marcusrichards.dev.

## Status

Active. Edit HTML directly; keep the evidence-first voice: every claim on the
page should be checkable.
